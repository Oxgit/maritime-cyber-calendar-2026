About Maritime Cybersecurity Conference Calendar - MC³ 2026

Maritime Cybersecurity Conference Calendar MC³ is a calendar of conferences, summits, and events dedicated to cybersecurity in the maritime sector for 2026.

Who is it for?

The calendar is designed for:

  • 🚢 Cybersecurity specialists in the maritime and port sector
  • ⚓ Security officers of shipping companies and port operators
  • 🔒 Consultants specializing in maritime cybersecurity
  • 🎓 Researchers working on MT/OT/IT security in maritime transport
  • 🏛️ Representatives of regulators and international organizations (IMO, EMSA, NATO)

Event types

The calendar covers various types of events:

TypeDescription
ConferenceClassic conferences with presentations and panels
SummitHigh-level meetings of industry leaders
ExpoTrade fairs with exhibitors and demo zones
ForumDiscussions and workshops in smaller groups
SymposiumAcademic and research meetings
TrainingPractical trainings and courses

Icons and labels

  • 🔒 Dedicated Cyber Track - event has dedicated sessions or track for cybersecurity
  • CFP - Call for Papers is open
  • 🌐 Online - event is fully or partially online
  • ~ - Date is tentative and may change

How to add an event?

If you want to add an event to the calendar, send information to the email address in the footer or open an Issue/PR in the project repository.

Information needed to add an event:

  • Event name
  • Date and location
  • Link to event website
  • Short description
  • Topic tags
  • Information about cyber track

Technology

The calendar is built using:

  • Hugo - static site generator
  • Custom theme inspired by konferencje.szurek.tv
  • GitHub Actions for automatic deployment

Key Maritime Cybersecurity Organizations

  • Maritime Cyber Guild - a non-profit organization dedicated to advancing cybersecurity within the maritime industry.
  • NORMA Cyber - Norwegian Maritime Cyber Resilience Centre
  • IMO - International Maritime Organization
  • EMSA - European Maritime Safety Agency
  • MTS-ISAC - Maritime Transportation System ISAC
  • NATO NMIOTC - Maritime Interdiction Operational Training Centre
  • France Cyber Maritime - M-CERT
